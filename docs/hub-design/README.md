1. [`01-brief.md`](01-brief.md)：美术指导写给施工方的任务书（背景、现有文件、素材、美术方向、已知 bug、第一轮的要求：只提意见，不改文件）。

3. [`03-decisions.md`](03-decisions.md)：美术指导的决定：采纳什么、改什么、加什么，并授权施工。
